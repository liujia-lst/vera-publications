Publications website

Maintenance options

Three options for adding publications, updating their details and managing research topics.

OptionEditing workflowPublishingSetup and trade-offs
Google Sheets Edit rows in a Publications sheet. Add categories to a separate Topics sheet and select them from a dropdown. A configured synchronization job imports the sheet data and rebuilds the website. Convenient for shared editing. Requires a shared sheet, public CSV exports and synchronization setup. CSV import scripts are available; the sheet connection is pending.
Decap CMS Log in to an editor, fill in a publication form and select or create topics. The CMS saves changes to GitHub, triggering the website build. Combines editing and publishing in one interface. Requires repository access and an authentication service. Setup is needed.
Browser form + GitHub upload Edit papers and topics in the publication editor, save a draft and download catalog.json. Upload the file to the repository's data/ folder. GitHub Actions publishes the update. Available now. Requires repository write access and a manual upload. Each editing session should start from the latest shared data file to avoid overwriting another editor's changes.

Recommendation

Google Sheets is a practical choice for regular shared editing, particularly if Kanda already works with spreadsheets. The current browser form is ready to try. A CMS may be useful later if the team website also needs editable people, projects and news pages.

The sheet or CMS connection would be configured after selecting the preferred workflow.
